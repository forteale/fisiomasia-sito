═══════════════════════════════════════════════════════════
   1. PUBBLICARE SU NETLIFY CON CMS (PRIMA VOLTA)
═══════════════════════════════════════════════════════════

PER USARE IL CMS SERVE UN REPOSITORY GITHUB (gratuito).

PASSO 1 — Crea il repository GitHub:
  - Vai su https://github.com/new
  - Nome: fisiomasia-sito (o quello che preferisci)
  - Privato (consigliato)
  - Crea il repository

PASSO 2 — Carica i file dello zip nel repository:
  Opzione A (web): apri il repository, "uploading an existing file",
    trascina tutti i file dello zip, fai commit.
  Opzione B (terminale):
    git clone https://github.com/TUO-USERNAME/fisiomasia-sito.git
    cd fisiomasia-sito
    # copia qui tutti i file dello zip
    git add .
    git commit -m "Sito iniziale"
    git push

PASSO 3 — Connetti Netlify a GitHub:
  - https://app.netlify.com → "Add new site" → "Import from Git"
  - Scegli GitHub, autorizza, seleziona fisiomasia-sito
  - Build settings (gia in netlify.toml):
       Build command:    node build-articoli.js
       Publish directory: .
  - "Deploy site"

PASSO 4 — Collega il dominio fisiomasia.it:
  - Pannello sito → "Domain settings" → "Add custom domain"
  - Inserisci fisiomasia.it e segui le istruzioni DNS

PASSO 5 — Attiva Netlify Identity (login per il CMS):
  - Pannello → "Identity" → "Enable Identity"
  - Settings → Registration: "Invite only"
  - Services → Git Gateway → "Enable Git Gateway"
  - Identity → "Invite users" → invita fabiana.masia@gmail.com
    (riceve un'email per creare la password)


═══════════════════════════════════════════════════════════
   2. COME PUBBLICARE UN ARTICOLO (Fabiana)
═══════════════════════════════════════════════════════════

1. Vai su https://fisiomasia.it/admin/
2. Login con email + password di Netlify Identity
3. Click "Articoli del blog" → "New Articolo"
4. Compila: titolo, data, categoria, estratto, immagine, contenuto
5. Click "Publish" → "Publish now"
6. In 1-2 minuti l'articolo è online sul sito.

L'articolo si vede a TUTTI da QUALSIASI dispositivo.
